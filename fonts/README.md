# Iosevka

Docker-based build scripts for my customized [Iosevka](https://github.com/be5invis/Iosevka) font and its [Nerd Font](https://github.com/ryanoasis/nerd-fonts) patched version (for Neovim).

Run `make` to build the fonts from latest release tags in both repos and package into `fonts-iosevka_*.deb`.
